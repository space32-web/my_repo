# my_repo

My first Git repo — учебный репозиторий для освоения основных команд Git.

## Что отрабатывается

- клонирование репозитория;
- добавление, изменение и удаление файлов;
- коммиты и отправка изменений на сервер;
- работа с ветками и слияние.

## Основные команды

| Команда | Назначение |
|---|---|
| `git clone <url>` | Скопировать репозиторий |
| `git add <файл>` | Добавить изменения в индекс |
| `git commit -m "..."` | Зафиксировать изменения |
| `git push` | Отправить на сервер |
| `git switch -c feature` | Создать ветку и перейти в неё |
| `git merge feature` | Слить ветку в текущую |
